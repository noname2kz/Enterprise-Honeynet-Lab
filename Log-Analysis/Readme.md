
# Phân tích nhật ký (Log Analysis)

Phần này trình bày quá trình thu thập, giám sát và phân tích nhật ký từ các thiết bị mạng, máy chủ và hệ thống giám sát trong môi trường Honeynet.

## 1. Phân tích nhật ký mạng

Phân tích lưu lượng mạng và các cảnh báo được ghi nhận bởi Suricata nhằm phát hiện hoạt động bất thường.

[Xem chi tiết](network-logs.md)

## 2. Phân tích nhật ký hệ thống

Phân tích nhật ký từ các máy chủ Honeypot được triển khai trong hệ thống.

[Xem chi tiết](system-logs.md)
